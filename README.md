# 페이앤밴 × 네이버 커넥트 렌탈 상세페이지

피그마 `페이앤밴_렌탈 상세페이지 › 커넥트렌탈` 디자인을 반응형 웹페이지로 옮긴 프로젝트입니다.
[toss-rental](https://github.com/ncandyyy/toss-rental) 과 같은 방식(빌드 없는 순수 HTML/CSS/JS → 넷리파이, 신청은 구글 시트 + 슬랙)으로 만들었습니다.
`public` 폴더를 그대로 넷리파이에 올리면 됩니다.

## 폴더 구조

```
.
├── netlify.toml                 # 넷리파이 설정 (public 폴더 배포)
├── apps-script/
│   └── Code.gs                  # 구글 시트 저장 + 슬랙 알림 + 누적 조회수 (Google Apps Script, 토스 렌탈과 공용)
├── docs/
│   └── form-setup.md            # 시트·슬랙 연결 방법
└── public/                      # ← 실제로 배포되는 폴더
    ├── index.html               # 페이지 전체 마크업 (섹션별 주석으로 구분)
    ├── css/
    │   ├── base/                # 디자인 토큰(색·단위), 리셋, 공통 스타일·등장 애니메이션
    │   ├── components/          # 라벨/태그, 자동 캐러셀, 움직이는 화면(영상), 신청 폼, 하단 버튼, 토스트
    │   └── sections/            # 섹션별 스타일 (topbar, hero, pain, package, reviews, devices, apply, footer)
    ├── js/
    │   ├── config.js            # ★ 운영 설정: 신청 접수 주소, 업종 목록, 상담 시간, 휴무일
    │   ├── main.js              # 진입점
    │   └── modules/             # 기능별 코드 (폼, 캐러셀·후기 줄 나누기, 카드 쌓기, 영상 재생, 숫자 카운트업, 등장효과, 유입경로 저장 등)
    └── assets/
        ├── images/              # 피그마에서 추출한 이미지 (WebP) + 공유 미리보기(og)
        ├── icons/               # 이모지·로고·아이콘
        └── videos/              # 첨부 GIF 를 영상으로 바꾼 것 (README 참고)
```

| `.hero` | 00히어로 | 형광펜 두 줄이 차례로 그어짐, 점선 궤도 천천히 회전, 기기 3종 순차 등장 후 둥실둥실, 혜택 라벨이 **점선 원을 따라 천천히 공전**(90초에 한 바퀴, 글씨는 항상 똑바로·기기 사진보다 위, 마우스 올리면 멈추고 기울며 떠오름) |

| `.devices` | 4 | 기기 순차 등장, 유리 라벨 둥실, 0원 숫자 슬롯 굴림, "내 기계로 소유" 빛 스침 |
| `.apply` | 5 + 폼 1·2·3 | 태그 그어짐, 비교 카드 등장·체크 그려짐, 초록 강조 띠 3개가 스티커처럼 하나씩 붙음, 3단계 신청 폼 |

## 피그마와 다르게 처리한 부분

- **상단 바 문구**: 피그마의 "지금 24명의 사장님이 관심있게 보고 있어요" 대신 toss-rental 과 같이 실제 누적 조회수 "지금까지 N명의 사장님이 관심있게 봤어요" 로 표시합니다. (미리 넣어둔 가짜 숫자 없음)
- **움직이는 화면**: 패키지 1·2번 카드의 정지 이미지를 첨부 GIF 로 교체하되, 용량 때문에 영상(mp4/webm)으로 변환했습니다 → [assets/videos/README.md](public/assets/videos/README.md)
- **단계 카드(01 아래)**: 카드 쌓기 효과를 위해 피그마보다 크게(폭 724 → 800, 화면 1.25배, 카드 높이는 화면 높이에 맞춤) 보여줍니다. 화면 높이가 600px 미만이면 쌓지 않고 일반 목록으로 보입니다.
- **이모지**: 불꽃·사이렌은 피그마 안의 움직이는 GIF(512px, 0.5~0.8MB)를 화면 크기의 약 3배로 줄인 애니메이션 WebP(80~140KB)로 넣었습니다.
- **"1년 쓰고나면" 박스**: 피그마에서 왼쪽 끝이 위 박스보다 6px 안쪽에 있어, 위 두 박스와 양끝을 맞췄습니다.
- **신청 폼**: toss-rental 과 같이 3단계에 개인정보 수집·이용 동의 체크를 넣었습니다.
- **기기 사진**: 피그마에 올라간 원본 이미지에서 피그마와 같은 크기·자르기로 잘라 썼습니다 (화면 대비 1.5~2배 해상도).

## 반응형 방식

- 피그마 원본 폭 **860px** 기준입니다. CSS 변수 `--u` 가 "디자인 1px" 이고, 화면이 860px보다 좁으면 비율대로 줄어듭니다.
- 글자는 너무 작아지지 않게 `max(최소px, 디자인값 × --u)` 로 최소 크기를 둡니다.
- 600px 미만(휴대폰)에서는 단계 카드를 글 위·화면 아래로 배치하고(화면 높이에 맞춰 최대한 크게), 고민 말풍선은 줄을 바꿉니다.
- 860px 보다 넓은 화면에서는 가운데 860px 칼럼 + 섹션 배경은 화면 끝까지 채웁니다.
- 이미지 위치를 바꾸고 싶으면 HTML 의 `style="--x: ..; --y: ..; --w: .."` 숫자(피그마 좌표)를 고치면 됩니다.

## 로컬에서 보기

```bash
npx serve public
```

(또는 `python3 -m http.server 8080 --directory public` 후 http://localhost:8080)

## 넷리파이 배포

- **Git 연결**: 넷리파이에서 이 저장소를 연결하면 `netlify.toml` 대로 `public` 폴더가 배포됩니다. 빌드 명령 없음.
- **드래그 앤 드롭**: https://app.netlify.com/drop 에 `public` 폴더를 끌어다 놓아도 됩니다.
